# 🛒 Superstore Sales Data Analysis

## 📌 Project Overview
This project analyzes a Superstore sales dataset using Python.

The goal of this project is to:
- clean and process sales data
- analyze sales and profit trends
- visualize business insights using graphs

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Analysis Performed
- Total sales analysis
- Sales by category
- Monthly sales trends
- Top cities by sales
- Profit analysis
- Discount vs profit analysis
- Correlation heatmap

---

## 📈 Visualizations Included
- Bar charts
- Line charts
- Scatter plots
- Heatmap

---

## 🔥 Key Insights
- Technology generated high sales and profits
- Higher discounts often reduced profits
- Some cities contributed significantly more sales
- Sales varied across different months

---

## 📂 Dataset
Global Superstore Dataset
